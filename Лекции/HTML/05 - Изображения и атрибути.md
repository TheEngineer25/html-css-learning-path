


# 📘 Изображения и атрибути

> [!abstract] Какво ще науча?
> - Ще разбера как да вмъквам изображения.
> - Ще разбера какво са атрибутите.

---

## 01 · Теория

Нещо, което липсва в нашата публикация, са изображенията. Затова нека да видим как да използваме елемента `<img>` и да вмъкнем такива.
Казахме, че елементът `<img>` е специален, понеже няма съдържание и няма затварящ таг.
Ако обаче не посочваме съдържание за този елемент, тогава как HTML ще знае кой елемент да посочи? За тази цел ние ще използваме нещо ново, наречено **атрибут**.

>[!important] Важно
>Атрибутите са част от данните, които описват елементите.

### Основни понятия

| **Елемент / Таг** | **Описание**                                                                        |
| ----------------- | ----------------------------------------------------------------------------------- |
| `<img>`           | Основният елемент за задаване на изображения                                        |
| `src`             | Задава пътя до изображението                                                        |
| `alt`             | Алтернативен текст, използва се в случаи, когато изображението не може да се зареди |
| `width`           | Задава ширината на изображението                                                    |
| `height`          | Задава височината на изображението                                                  |

---

## 02 · Примери с код

### HTML

```html
<img src="" alt="">
```

### CSS

```css
.card {
  padding: 20px;
  border-radius: 12px;
  background-color: #f3f6fa;
}

.card h2 {
  color: #2563eb;
}
```
