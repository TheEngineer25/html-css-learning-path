## 01 · Теория

## 02 · Примери с код

### HTML

```html
<div class="card">
  <h2>Здравей, свят!</h2>
  <p>Моят първи пример.</p>
</div>
```

### CSS

```css
.card {
  padding: 20px;
  border-radius: 12px;
  background-color: #f3f6fa;
}

.card h2 {
  color: #2563eb;
}
```
