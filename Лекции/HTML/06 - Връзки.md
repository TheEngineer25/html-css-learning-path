


# 📘 Връзки

> [!abstract] Какво ще науча?
> - Ще разбера как да създавам линкове/връзки.
> - Ще мога да ги използвам на практика.

---

## 01 · Теория

Еди от основните градивни блокове на интернет. Връзките позволяват на интернет да бъде това, което всъщност е - световна мрежа. Затова нека сега да се научим да поставяме линкове в страниците ни.

### Основни понятия

| **Елемент / Таг** | **Описание**                                                      |
| ----------------- | ----------------------------------------------------------------- |
| `<a>`             | Основен елемент за задаване на линкове/връзки                     |
| `href`            | Атрибут, посочващ URL адреса на линка                             |
| `target=_blank`   | Атрибут, който отваря страницата на нов раздел. Има и други опции |
| `#`               | Задава празен, неработещ линк                                     |


---

## 02 · Примери с код

### HTML

```html
<p>You can learn more at the <a href="https://developer.mozilla.org/en-US/docs/Web/HTML" target="_blank">MDN Web Docs</a>.</p>
```

### CSS

```css
.card {
  padding: 20px;
  border-radius: 12px;
  background-color: #f3f6fa;
}

.card h2 {
  color: #2563eb;
}
```
