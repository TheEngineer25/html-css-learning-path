# 02 - HTML структура на документа

**Дата:** 15.10.2026

## 🎯 Цел на урока

Да разберем основните тагове, без които не може да се направи една уеб страница.

## 📖 Теория

Първото нещо, което трябва да научим за HTML, е общата структура на документа. Това е структура, която присъства във всеки един HTML документ.
Започваме с празна страница и първото нещо, което трябва да декларираме, е т.нар. `<!DOCTYPE>`.

## 💻 Пример

```html
<!DOCTYPE html>
```

След това ние трябва да създадем `<html>` елемент.

## 💻 Пример

```html
<!DOCTYPE html>
<html>

</html>
```

Относно съдържание, ние всъщност ще добавим нов елемент вътре в `<html>` и това ще бъде елемента ``
