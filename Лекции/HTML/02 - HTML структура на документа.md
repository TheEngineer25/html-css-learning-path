# HTML структура на документа

## 🎯 Какво представлява?

Първото нещо, което трябва да научим, преди да започнем да изучаваме HTML,е общата структура на документа. Това е структура, която присъства във всеки един HTML документ.
След като си имаме папката с проекта, трябва да създадем нов файл, който обикновено наричаме `index.html`.
Първото нещо, което правим, след като създадем този файл, е да направим т.нар. `DOCTYPE`.
### HTML

```html
<!DOCTYPE html>
```

**Обяснение:** по този начин казваме на браузъра, че ще използваме HTML.

След това ние трябва да създадем `<html>` елемент.

### HTML

```html
<!DOCTYPE html>
<html></html>
```

**Обяснение:** това е корена на документа (root елемент).

Що се отнася до съдържанието на този елемент, ние ще поставим друг елемент вътре в него. Вътре ние ще искаме елемента `<head>`.

### HTML

```html
<!DOCTYPE html>
<html>
<head></head>
</html>
```

**Обяснение:** това е за неща, които обикновено не се виждат в браузъра, като мета информация, връзка към CSS и др.

След това имаме елемента `<body>`.

### HTML

```html
<!DOCTYPE html>
<html>
<head></head>

<body></body>
</html>
```

**Обяснение:** `<body>` е за видимата част на страницата. Всичко, което ние виждаме, се намира вътре в този елемент.

Нека в елемента `<head>`  да уточним заглавието на страницата. Това става с помощта на елемента `<title>`.

### HTML

```html
<!DOCTYPE html>
<html>
<head>
	<title>The Basic Language of the Web: HTML</title>
</head>

<body></body>
</html>
```

Вместо да оставяме елемента `<body>` пазен, нека всъщност да добавим едно заглавие там. 

### HTML

```html
<!DOCTYPE html>
<html>
<head>
	<title>The Basic Language of the Web: HTML</title>
</head>

<body>
	<h1>The Basic Language of the Web: HTML</html>
</body>
</html>
```

По този начин ние научихме основната структура на един HTML документ.

## 📌 Важни неща за запомняне

- Всеки HTML документ трябва да притежава основната структура
- Всеки HTML документ трябва да започва с `<html>` и да завършва с `</html>`
- `<head>` е за елементи, които не се виждат на страницата
- `<body>` е за всички елементи, които ще се виждат на страницата


## 💡 Какво научих?

Моето обобщение:

Всеки HTML документ си има структура, която е задължителна за използване. Първото нещо, с което се започва, е т.нар. `<!DOCTYPE html>`, който указва, че документът ще използва HTML. 
След това имаме root елемента `<html>`. 
След това имаме елемента `<head>`, който е за неща, които не се виждат от браузъра. В него ние вмъкнахме елемента `<title>`, който указва заглавието на нашата страница.
Елементът `<body>` е за неща, които всъщност ще се покажат в браузъра - текст, бутони, изображения и др. Ние добавихме заглавие чрез елемента `<h1>`.

## ❓ Въпроси за преговор

- какво е `<!DOCTYPE html>`
- какво е `<html>`
- какво е `<head>`
- какво е `<title>`
- за какво служи елемента `<body>`
