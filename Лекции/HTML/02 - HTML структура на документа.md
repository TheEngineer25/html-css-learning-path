# 02 - HTML структура на документа

**Дата:** 15.10.2026

## 🎯 Цел на урока

Да разберем основните тагове, без които не може да се направи една уеб страница.

## 📖 Теория

Първото нещо, което трябва да научим за HTML, е общата структура на документа. Това е структура, която присъства във всеки един HTML документ.
Започваме с празна страница и първото нещо, което трябва да декларираме, е т.нар. `<!DOCTYPE>`.

## 💻 Пример

```html
<!DOCTYPE html>
```

След това ние трябва да създадем `<html>` елемент.

## 💻 Пример

```html
<!DOCTYPE html>
<html>

</html>
```

Относно съдържание, ние всъщност ще добавим нов елемент вътре в `<html>` и това ще бъде елемента `<head`>

## 💻 Пример

```html
<!DOCTYPE html>

<html>

  <head></head>

</html>

```

Сега да добавим и елемента `<body>`.

## 💻 Пример

```html
<!DOCTYPE html>

<html>

  <head></head>
  
  <body></body>

</html>

```

И така, всеки един HTML документ трябва да започва с елемента `<head>`. След това ние имаме нужда от елемента `<head>` и после от `<body>`.
`<head>` е предназначен за неща, които не се виждат в браузъра, като например заглавието на страницата, допълнителна информация за нея, връзка към CSS и др. Засега ще попълним единствено заглавието на страницата с тага `<title>`.

## 💻 Пример

```html
<!DOCTYPE html>

<html>

  <head>
      <title>The Basic Language of the Web: HTML </title>
  </head>
  
  <body></body>

</html>

```

След това `<body>` всъщност е за елементи, които се виждат на страницата. Нека да си добавим едно заглавие.

## 💻 Пример

```html
<!DOCTYPE html>

<html>

  

<head>

  <title>The Basic Language of the Web: HTML</title>

</head>

  

<body>

  <h1>The Basic Language of the Web: HTML</h1>

</body>

  

</html>

```

Нека сега да видим това в браузъра.
