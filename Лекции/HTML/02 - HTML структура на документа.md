# HTML структура на документа

## 🎯 Какво представлява?

Първото нещо, което трябва да научим, преди да започнем да изучаваме HTML,е общата структура на документа. Това е структура, която присъства във всеки един HTML документ.
След като си имаме папката с проекта, трябва да създадем нов файл, който обикновено наричаме `index.html`.
Първото нещо, което правим, след като създадем този файл, е да направим т.нар. `DOCTYPE`.
### HTML

```html
<!DOCTYPE html>
```

**Обяснение:** по този начин казваме на браузъра, че ще използваме HTML.

След това ние трябва да създадем `<html>` елемент.

### HTML

```html
<!DOCTYPE html>
<html></html>
```

**Обяснение:** това е корена на документа (root елемент).

Що се отнася до съдържанието на този елемент, ние ще поставим друг елемент вътре в него. Вътре ние ще искаме елемента `<head>`.

### HTML

```html
<!DOCTYPE html>
<html>
<head></head>
</html>
```

**Обяснение:** това е за неща, които обикновено не се виждат в браузъра, като мета информация, връзка към CSS и др.

След това имаме елемента `<body>`.

### HTML

```html
<!DOCTYPE html>
<html>
<head></head>

<body></body>
</html>
```

**Обяснение:** `<body>` е за видимата част на страницата. Всичко, което ние виждаме, се намира вътре в този елемент.
