# 04 - Още текстови елементи - списъци

**Дата:** 15.10.2026

## 🎯 Цел на урока

Да се научим да създаваме подреден и неподреден списък.


## 📖 Теория

Списъците се правят много лесно в HTML. Нека да видим как.
Започваме с номериран списък. За да го направим, ние имаме нужда от елемента `<ol>`.
## 💻 Пример

```html

<ol></ol>

```

Самите елементи на списъка се правят с елемента `<li>`.

## 💻 Пример

```html

<ol>
	<li>The opening tag</li>
	<li>The closing tag</li>
	<li>The actual element</li>
</ol>

```

Да видим как изглежда това.

![[13.png]]

За направата на неподреден списък имаме тага `<ul>`.

## 💻 Пример

```html

<ul></ul>

```

За направата не неговите елементи отново използваме елемента `<li>`.

## 💻 Пример

```html

<ul>
	<li>To be able to use the fundamental web dev language</li>
	<li>To hand-craft beautiful websites instead of relying on tools like Worpress or Wix</li>
	<li>To build web applications</li>
	<li>To impress friends</li>
	<li>To have fun 😃</li>
</ul>

```
