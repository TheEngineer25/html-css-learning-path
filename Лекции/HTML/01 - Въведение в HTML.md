## 01 · Теория

>[!note] Забележка
> - HTML произлиза от HYperText Markup Language
> - HTML е маркиращ език за структуриране на съдържанието на една уеб страница (не е програмен език)
> - HTML използва **тагове**, за да опише различно съдържание - параграфи, линкове, изображения и др.
>  - Уеб бразърите разбират HTML и го представят като цял уебсайт

Нека сега да разгледаме анатомията на един HTML елемент.

![[1.png]]

| Елемент                                      | Как изглежда               | Описание                     |
| :------------------------------------------- | :------------------------- | :--------------------------- |
| **<font color="#4CAF50">Начален таг</font>** | `<p>`                      | Началото на елемента         |
| **<font color="#2196F3">Съдържание</font>**  | `HTML is a markup language | Текстът или вътрешността     |
| **<font color="#FF5722">Краен таг</font>**   | `</p>`                     | Обозначава края на параграфа |

Това е всичко, от което имаме нужда, за да започнем да пишем HTML..

## 02 · Примери с код

### HTML

```html
<div class="card">
  <h2>Здравей, свят!</h2>
  <p>Моят първи пример.</p>
</div>
```

### CSS

```css
.card {
  padding: 20px;
  border-radius: 12px;
  background-color: #f3f6fa;
}

.card h2 {
  color: #2563eb;
}
```
