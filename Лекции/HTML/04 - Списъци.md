


# 📘 Списъци

> [!abstract] Какво ще науча?
> - Ще разбера как да създавам подреден и неподреден списък.
> - Ще мога да ги използвам на практика.

---

## 01 · Теория

Да се научим как да правим списъци с точки и числа.
Това е много лесно да се направи с HTML. Нека да видим как.
Започваме с номерирания списък.


---

## 02 · Примери с код

### HTML

```html
<ol>
	<li>The opening tag</li>
	<li>The closing tag</li>
	<li>The actual element</li>
</ol>
```

![[4.png]]

---

По този начин създаваме подреден списък.
Сега да видим как можем да създадем неподреден списък.


### HTML

```html
<ul>

    <li>To be able to use the fundamental web dev language</li>

    <li>To hand-craft beautiful websites instead of relying on tools like Worpress or Wix</li>

    <li>To build web applications</li>

    <li>To impress friends</li>

    <li>To have fun 😃</li>

  </ul>
```
