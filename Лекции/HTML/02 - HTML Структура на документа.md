


# 📘 HTML Структура на документа

> [!abstract] Какво ще науча?
> - Ще разбера кои тагове се използват за създаване на един HTML документ
> - Ще мога да ги използвам на практика.

---

## 01 · Теория

Първото нещо, което трябва да научим за HTML, е неговата обща структура, която присъства във всеки HTML документ.


### Основни понятия

| **Елемент / Таг**     | **Описание**                                                                                                                                                                                                |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **`<!DOCTYPE html>`** | Декларация (не е строго таг), която указва на браузъра коя версия на HTML се използва (в случая HTML5), за да се визуализира страницата правилно.                                                           |
| **`<html>`**          | Главният (коренов) контейнер, който обхваща целия HTML документ. Всички останали елементи са вложени вътре в него.                                                                                          |
| **`<head>`**          | Секцията за метаинформация. Тук се слагат заглавието на страницата (`<title>`), връзки към стилове (`<link>`), скриптове и настройки, които **не** се виждат директно в самия работен прозорец на браузъра. |
| **`<body>`**          | Основното тяло на документа. Всичко, което напишеш тук (текстове, изображения, бутони, параграфи като `<p>`), се показва видимо на екран в браузъра.                                                        |

---

## 02 · Примери с код

### HTML

```html
<!DOCTYPE html>

<html>

  <head></head>

  <body>

  </body>

  
</html>
```

С това научихме основната структура на HTML.


### CSS

```css
.card {
  padding: 20px;
  border-radius: 12px;
  background-color: #f3f6fa;
}

.card h2 {
  color: #2563eb;
}
```
