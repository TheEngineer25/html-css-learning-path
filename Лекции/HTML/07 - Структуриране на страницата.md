# 07 - Структуриране на страницата

**Дата:** 16.10.2026

## 🎯 Цел на урока

Ще научим как да структурираме страницата си с помощта на още елементи.

## 📖 Теория

Време е да добавим някаква структура на нашата страница и към нашие елементи. Затова сега ще научим още няколко нови елемента.
Когато казахме, че на страницата ѝ липсва структура, имахме предвид, че всички тези елементи някак си се появяват един след друг. Те се не разграничават един друг и не са групирани по някакъв логически начин. Затова ние ще променим това, като създадем няколко контейнерни елемента, които ще групират тези елементи заедно.
Едно от първите неща, за които се сещаме, са линковете в началото на страницата. Това много прилича на навигация и за щастие в HTML5 ние имаме точно такъв елемент, а именно `<nav>`.
## 💻 Пример

```html
<nav>
	<a href="blog.html">Blog</a>
	<a href="#">Challenges</a>
	<a href="#">Flexbox</a>
	<a href="#">CSS Grid</a>
</nav>
```

Когато актуализираме страницата, това не променя абсолютно нищо. Ние просто създаваме нещо като невидима бариера, която просто държи тези елементи.
Всичко останало след заглавието по същество е нашата публикация. Това и е доста различно от горната част.
Затова това, което можем да направим, е да групираме навигацията със заглавието в един елемент, който се нарича `<header>`.

## 💻 Пример

```html
<header>
    <h1>📘 The Code Magazine</h1>
    <nav>
	    <a href="blog.html">Blog</a>
	    <a href="#">Challenges</a>
	    <a href="#">Flexbox</a>
	    <a href="#">CSS Grid</a>
	</nav>
</header>
```

`<header>` означава най-горната част на един HTML документ.
Отново, абсолютно нищо няма да се промени визуално, но сега казваме на браузъра, че всичко това е `<header>`.
След това всичко останало, както казахме, е нашата публикация. Има доста често срещан елемент, който можем да използваме, и това е елементът `<article>`.
Ние обаче можем да продължим с групирането.
За най-долната част на страницата ние имаме елемента `<footer>`.

## 💻 Пример

```html
<footer>Copyright &copy; 2027 by The Code Magazine.</footer>
```
