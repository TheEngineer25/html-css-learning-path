


# 📘 Структуриране на страницата

> [!abstract] Какво ще науча?
> - Ще науча още няколко полезни елемента.
> - Ще науча основните на структуриране на страница.

---

## 01 · Теория

Време е да добавим някаква структура на нашата страница и елементи. Затова сега ще научим още няколко нови HTML5 елемента за целта.
Когато казваме, че на страницата ѝ липсва структура, имаме предвид, че всички тези елементи просто се появяват един след друг и по никакъв начин не са разграничени и най-вече - те не са групирани по никакъв начин.
Затова ние ще създадем няколко контейнерни елемента, за да променим това.
Първото нещо, за което се сещаме, са линковете в началото на страницата. Те приличат на навигация и за щастие в HTML5 има елемент, който служи за това - `<nav>`.

### HTML

```html
<nav>

    <a href="#">Blog</a>

    <a href="#">Challenges</a>

    <a href="#">Flexbox</a>

    <a href="#">CSS Grid</a>

  </nav>
```

Когато обаче актуализираме нашата страница, няма да видим никаква промяна. Ние просто създаваме нещо като невидима кутия, която държи елементите групирани заедно.
След навигацията имаме нашето заглавие, а всичко останало е нашия пост. Всичко това е различно от частта най-горе.
Това, което можем да направим, е а да групираме заглавието и навигацията в нов елемент, който се нарича `<header>`.

```html
<header>

    <h1>📘 The Code Magazine</h1>

	<nav>

      <a href="#">Blog</a>

      <a href="#">Challenges</a>

      <a href="#">Flexbox</a>

      <a href="#">CSS Grid</a>

    </nav>

  </header>
```

`<header>` обозначава най-горната част на един уеб документ.
Отново, нищо не се променя визуално, но сега казваме на браузъра кое всъщност е горната част на нашата страница.
След това всичко останало е нашата публикация. Много често срещан елемент, който можем да използваме, е елементът `<article>`.
Ако всички тези елементи, които поставяме не правят нищо, тогава защо не поставим всички като `<nav>`? Ние не правим това, поради нещо, наречено **семантичен HTML**, за който ще говорим в следващата лекция.
Нека обаче да продължим с групирането на нашите елементи.
