


# 📘 Текстови елементи

> [!abstract] Какво ще науча?
> - Ще разбера как да използвам параграфи и заглавия.
> - Ще разбера как да направя текста удебелен или курсив.

---

## 01 · Теория

Целта на заглавията е да разделят големи блокове от текст на логически смислени части. Имаме цели шест заглавия, т.е. има йерархия на заглавията.

### Основни понятия

- **Понятие 1** — обяснение.
- **Понятие 2** — обяснение.

---

## 02 · Примери с код

### HTML

```html
<h1>The Basic Language of the Web: HTML</h1>
<h2>The Basic Language of the Web: HTML</h2>
<h3>The Basic Language of the Web: HTML</h3>
<h4>The Basic Language of the Web: HTML</h4>
<h5>The Basic Language of the Web: HTML</h5>
<h6>The Basic Language of the Web: HTML</h6>
```


![[2.png]]

Създава се визуална йерархия със заглавията.
Сега да видим как можем да използваме параграфи.


```html
<p>Posted by Laura Jones on Monday, June 21st 2027</p>
```

>[!important] Важно
>Всяка страница трябва да има само един `<h1>`

Сега да видим как можем да правим удебелен и наклонен текст.

| Таг        | Име      | Описание                         | Пример                         |
| ---------- | -------- | -------------------------------- | ------------------------------ |
| `<b>`      | Bold     | Прави текста удебелен (визуално) | `<b>Laura Jones</b>`           |
| `<strong>` | Strong   | Важен текст (семантично)         | `<strong>Laura Jones</strong>` |
| `<i>`      | Italic   | Прави текста курсив              | `<i>fundamental</i>`           |
| `<em>`     | Emphasis | Курсивен текст (семантично)      | `<em>fundamental</em>`         |


### CSS

```css
.card {
  padding: 20px;
  border-radius: 12px;
  background-color: #f3f6fa;
}

.card h2 {
  color: #2563eb;
}
```

## 04 · Често срещани грешки

> [!warning] Внимавай!
> С наличието на HTML5 вече не се препоръчва използването на `<i>` и `<b>` поради нещо, наречено **семантичен HTML.** Ще разгледаме семантичния HTML малко по-късно.
