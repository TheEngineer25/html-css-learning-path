# 03 - Текстови елементи

**Дата:** 15.10.2026

## 🎯 Цел на урока

Ще продължим да работим със заглавия и параграфи и ще започнем изграждането на първия ни проект, а също така ще видим как да направим текста ни удебелен или наклонен.

## 📖 Теория

Започваме със заглавията.
Обикновено тяхната цел е да разделят големи блокове на логически смислени части.
Ние вече научихме за `<h1>`, но всъщност заглавията са цели шест, т.е. има йерархия на заглавията.
Нека да видим всички заглавия.

## 💻 Пример

```html

<h1>The Basic Language of the Web: HTML</h1>

  <h2>The Basic Language of the Web: HTML</h2>

  <h3>The Basic Language of the Web: HTML</h3>

  <h4>The Basic Language of the Web: HTML</h4>

  <h5>The Basic Language of the Web: HTML</h5>

  <h6>The Basic Language of the Web: HTML</h6>

```

Сега вече знаем как работят различните заглавия.
Сега обаче постепенно да започнем да изграждаме нашия проект.

## 💻 Пример


Сега да създадем няколко допълнителни параграфа тук.

## 💻 Пример

```html

<h1>📘 The Code Magazine</h1>
<p>Posted by Laura Jones on Monday, June 21st 2027</p>

<h2>The Basic Language of the Web: HTML</h2>
<p>All modern websites and web applications are built using three fundamental technologies: HTML, CSS and JavaScript. These are the languages of the web. </p>

<p>In this post, let's focus on HTML. We will learn what HTML is all about, and why you too should learn it. </p>

<h3>What is HTML?</h3>
 
```

Да добавим и последните коментари.

## 💻 Пример

```html

<h1>📘 The Code Magazine</h1>
<p>Posted by Laura Jones on Monday, June 21st 2027</p>

<h2>The Basic Language of the Web: HTML</h2>
<p>All modern websites and web applications are built using three fundamental technologies: HTML, CSS and JavaScript. These are the languages of the web. </p>

<p>In this post, let's focus on HTML. We will learn what HTML is all about, and why you too should learn it. </p>

<h3>What is HTML?</h3>
<p>HTML stands for HyperText Markup Language. It's a markup language that web developers use to structure and describe the content of a webpage (not a programming language). </p>

<p>HTML consists of elements that describe different types of content: paragraphs, links, headings, images, video, etc. Web browsers understand HTML and render HTML code as websites. </p>
 
```

Нека да разгледаме.

![[9.png]]

И за финал на тази лекция нека да видим как може да правим удебелен и наклонен текст.
За удебелен текст имаме два начина, по които можем да го направим. Първият и вече остарял начин е с тага `<b>`.


## 💻 Пример

```html

<h1>📘 The Code Magazine</h1>
<p>Posted by <b>Laura Jones</b> on Monday, June 21st 2027</p>

<h2>The Basic Language of the Web: HTML</h2>
<p>All modern websites and web applications are built using three fundamental technologies: HTML, CSS and JavaScript. These are the languages of the web. </p>

<p>In this post, let's focus on HTML. We will learn what HTML is all about, and why you too should learn it. </p>

<h3>What is HTML?</h3>
<p>HTML stands for HyperText Markup Language. It's a markup language that web developers use to structure and describe the content of a webpage (not a programming language). </p>

<p>HTML consists of elements that describe different types of content: paragraphs, links, headings, images, video, etc. Web browsers understand HTML and render HTML code as websites. </p>
 
```

Сега да видим как можем да направим текста наклонен. И пак като в предния случай, имаме два начина. По-старият начин е с тага `<i>`.

## 💻 Пример

```html
<p>HTML consists of elements that describe different types of content: paragraphs, links, headings, images, video, etc. Web browsers understand HTML and render HTML code as websites. </p>
 
```
