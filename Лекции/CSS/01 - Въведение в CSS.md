## 📖 Теория

> [!important] Важно
>  CSS е съкращение на Cascading Style Sheets
>  CSS описва визуалния стил и представянето на съдържанието, написано с HTML
>  CSS се състои от много `свойства`, които програмистите използват: за цвят, за фон, за текст и др.
